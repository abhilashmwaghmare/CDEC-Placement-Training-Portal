# CloudBlitz GenAI Placement Readiness Portal

A static, GitHub Pages-ready training portal for the CloudBlitz GenAI placement and project readiness program.

## Included

- Dashboard
- 15-day placement readiness roadmap
- Trainer Mode with day navigation and local completion tracking
- Generic GenAI Project SOP
- Project phase filtering: Day 1 Plan, Day 2 Build, Day 3 Validate, Day 4 Deploy & Handover
- Placement resources for Resume, LinkedIn, Naukri, Interview, Networking and Project Storytelling
- Training search
- Responsive CloudBlitz orange corporate UI

## Source-first data

The training content is stored in `data.js` and is presented from the supplied GenAI placement/project material. The portal does not require a backend.

## GitHub Pages

Open the `genai-placement-portal/` path from the repository's published Pages site.
